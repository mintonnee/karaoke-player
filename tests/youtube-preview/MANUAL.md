# 009 YouTube URL 미리보기 수동 검증

자동 fixture는 `pnpm test`로 통과한다. 아래는 Node 테스트가 대체하지 못하는 항목이다.
구현 완료 기록에 mock 통과만으로 기준 11·12를 충족했다고 쓰지 않는다.

## 기준 11 — UI·접근성

지원 zip 배포판에서 `pnpm dev` 또는 패키징 앱으로 가져오기 팝업을 연다.

- [ ] 상태 아이콘이 URL 입력 오른쪽 안에 있고, 긴 URL과 겹치지 않는다
- [ ] 좁은 창에서도 상태 문구가 라벨과 같은 줄 오른쪽에 있고, 곡 정보는 입력 아래에 있다
- [ ] idle / invalid / 확인 중 / 가능 / 차단 / 실패가 아이콘과 문구로 구분된다 (색만 아님)
- [ ] 조회 중에도 입력·방식 전환·닫기·Escape가 된다
- [ ] 실제 제출 중에는 004와 같이 잠긴다
- [ ] 스크린리더가 상태 문구를 읽고, `다시 확인`이 키보드로 닿는다

## 기준 9·12 — 실제 배포판 YouTube

lock 버전은 `build/locks/tools.lock.json`의 yt-dlp·deno 항목을 기록한다.

- [ ] lock 버전: yt-dlp `________` / deno `________`
- [ ] 접근 가능한 영상: 조회 → 제목·아티스트·커버 확인 → 수동 수정 → 가져오기 → 저장값·커버 → 분리·재생
- [ ] 네트워크 끊기 → 확인 실패 → 복구 후 `다시 확인` → 가져오기
- [ ] DRM·로그인 필요 등 실제 제한 사례를 확보했으면 코드와 문구를 적고, 없으면 fixture만 인정하고 미검증으로 남긴다
